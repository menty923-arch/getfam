# GETFAM

Strona agencji dla twórców internetowych. Projekt semestralny (HTML, CSS i czysty JavaScript, bez zależności).

## Uruchomienie

Otwórz `index.html` w przeglądarce. Strona działa offline, a formularze są w trybie demonstracyjnym (dane nie są wysyłane).

## Pliki

- `index.html` – strona główna (audyt profilu, przykład pracy, oferta, dla marek, kontakt)
- `o-projekcie.html` – podstrona z opisem modelu biznesowego
- `css/style.css`, `js/app.js` – style i skrypty
- `img/`, `fonts/` – grafiki i font
